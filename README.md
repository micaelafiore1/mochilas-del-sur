# Mochilas del Sur

Sistema web de gestión de stock desarrollado para la PyME
Mochilas del Sur.

## Objetivo

Desarrollar un sistema que permita gestionar productos,
stock y ventas de manera centralizada, reemplazando el
control manual mediante planillas y cuadernos.

## Tecnologías

- Python
- Flask
- SQLite
- HTML
- CSS
- Git
- GitHub

## Funcionalidades

- Login y autenticación
- Gestión de productos
- Gestión de stock
- Registro de ventas
- Alertas de stock mínimo
- Gestión de materias primas
